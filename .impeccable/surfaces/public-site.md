# Публичный сайт

Mode: Persuade; страницы программ и практики также поддерживают Read.
Авторитет: предоставленные PUBLIC_SITE_DESIGN_SPEC.md и восемь PNG в ZIP. Это концептуальные пары экранов, а не измеренные CSS goldens; текст и HEX имеют приоритет. Новая визуальная концепция не требуется.
Первый экран: два уровня Java, короткое объяснение практики, выбор маршрута и просмотр учебного сценария. Механизм — «Задача → Код → Проверка → Разбор»; схемы состоят из семантических узлов и контурных Lucide-иконок, без фиктивного работающего редактора.
Система: Golos Text, JetBrains Mono для кода, светлая и графитовая палитры из раздела 14; бирюзовое действие. Пространство и крупная типографика; чередование программ, практики, текста автора и спокойного завершения.
Маршруты: /, /courses, /courses/java, две Java-программы, /practice и её сценарий, /about, /contacts, /privacy. Вход /login переиспользует существующую авторизацию; кабинет /cabinet, старые /?view=… поддерживаются.
Неопределённые данные: адрес партнёра, контактный канал, API заявки и юридическая политика. До их предоставления нет активного сбора персональных данных и нет ложной отправки.
Проверка: lint/types/build; реальные браузерные переходы, фильтры, темы, клавиатура, no-JS; 320/390/768/1024/1440; регрессии кабинетов и настоящий вход через BFF на одноразовом backend. Скриншоты desktop/mobile в обеих темах и независимое финальное ревью.
