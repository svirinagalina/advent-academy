# Advent Academy

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Люди, начинающие Java либо укрепляющие базу после курсов и самостоятельного обучения; ученики, преподаватели, редакторы и администраторы существующей платформы.

## Product Purpose
Публичный сайт помогает выбрать один из двух маршрутов Java и ознакомиться с учебной практикой. Кабинеты обеспечивают обучение, проверку работ, встречи и управление контентом и пользователями.

## Capabilities and Constraints
Используется существующий Next.js frontend и BFF авторизации. Публичный вход ведёт в существующую форму; токены не доступны браузерному JavaScript. Публичные страницы не меняют правила доступа кабинетов.
Java с нуля и Java Advanced — два маршрута одного направления. Английский — направление партнёра Галины Свириной. Go готовится, записи нет.
Не утверждены контактный канал, URL партнёра, политика обработки данных и контракт заявок. Пока они отсутствуют, персональные данные для заявок не собираются и успешная отправка не имитируется.

## Brand Commitments
Русские тексты и композиция из frontend/design-reference/PUBLIC_SITE_DESIGN_SPEC.md и отдельно предоставленного Advent_Academy_Public_Design.zip. При расхождениях текст спецификации имеет приоритет над концептуальными PNG. Автор — Иван Пшыченко, Java-разработчик и ментор, согласно предоставленному материалу; фотография не предоставлена.

## Evidence on Hand
Предоставлены восемь парных макетов и спецификация. Программа обозначена как проект программы. Нет подтверждённых цен, сроков, отзывов, показателей трудоустройства и юридических условий; их нельзя выдумывать.

## Product Principles
Понятные требования и самостоятельная практика. Проверка результата и объяснение ограничений. Учебный проект не выдаётся за коммерческий опыт. Успех пользовательского действия подтверждается реальным сервером.

## Accessibility & Inclusion
Две темы, клавиатурная навигация, reduced motion, читабельность на 320 px и при 200% текста; основное публичное содержание доступно без JavaScript.
