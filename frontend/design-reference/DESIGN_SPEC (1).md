# Advent Academy — DESIGN_SPEC

Версия: дополнение к утверждённому кабинету ученика, 14.10.2026.

Тёмная тема, бирюзовый акцент и характер существующих макетов сохранены. Значения ниже — предлагаемые CSS-параметры для реализации на Next.js, React, TypeScript и Tailwind CSS; они не извлечены точно из PNG. Изображения служат визуальным ориентиром. При расхождениях в данных, состояниях и размерах использовать эту спецификацию. Продуктовые правила требуют согласования с backend.

## 1. Завершение урока

- Просмотр видео и открытие страницы не завершают урок.
- Без обязательного задания: кнопка «Завершить урок» отправляет запрос. До подтверждения следующий урок остаётся закрытым.
- Ожидание: «Завершаем…», индикатор, защита от повторного нажатия. Ошибка: «Не удалось завершить урок. Попробуйте ещё раз» и «Повторить». Прогресс не увеличивается.
- С обязательным заданием: ручной кнопки завершения нет. Урок завершается после принятия задания преподавателем.
- «На проверке» и «Нужны исправления» сохраняют следующий урок заблокированным.
- После подтверждённого принятия обновляются статус урока, программа, число завершённых уроков и прогресс; появляется «Следующий урок».
- Повторное открытие завершённого урока не сбрасывает прогресс. Повторный ответ о завершении не должен увеличивать счётчик второй раз.

Основные демонстрационные экраны сохраняют Java: 8 из 24, 33%. Фрагмент «Задание принято» показывает отдельное состояние после завершения текущего урока: 9 из 24, 38%, следующий урок «Циклы». Это переход состояния, а не изменение исходных данных.

## 2. Мобильная навигация и программа курса

На главной, в курсах, на странице курса, в заданиях и онлайн-занятиях присутствует нижняя навигация: «Главная», «Курсы», «Задания», «Занятия». Последние два коротких названия ведут в разделы «Задания» и «Онлайн-занятия».

Внутри урока нижняя навигация скрыта. «К курсу» возвращает на страницу курса; там доступны основные разделы. «Программа курса» открывает модальную выдвижную панель поверх урока. Самостоятельно стиль и основные макеты не меняются.

Панель:

- Название курса, число завершённых уроков и процент находятся в заголовочной области; ниже — прокручиваемый список модулей.
- По умолчанию открыт модуль с текущим уроком. Завершённый модуль можно раскрыть и выбрать урок для повторного просмотра.
- Текущий урок выделяется поверхностью, текстом «Текущий урок» и значком; завершённые — галочкой и подписью.
- Закрытые уроки имеют замок и видимую причину. «Циклы»: «После завершения урока “Условные операторы”». Нажатие на такой ряд только повторяет пояснение, не открывает материал.
- Выбор другого доступного урока закрывает панель и открывает выбранный урок с начала. Выбор текущего закрывает панель и возвращает к прежнему положению текущего урока.
- Закрытие: кнопка с доступным именем «Закрыть программу курса», нажатие на затемнённый фон вне панели или Escape. Эти действия возвращают прежнюю позицию страницы урока.
- Перед открытием сохраняется положение прокрутки страницы. Фоновая страница не прокручивается и недоступна для взаимодействия; прокручивается только содержимое панели. Не допускать перехода прокрутки со списка на фон.
- Панель — модальный dialog с названием. При открытии фокус получает заголовок панели, доступный программно; далее Tab/Shift+Tab остаются внутри. После обычного закрытия фокус возвращается на кнопку «Программа курса». После перехода к другому уроку — на его заголовок.
- Крестик остаётся доступным при прокрутке. При большом увеличении текста разрешено прокручивать всю внутреннюю область панели, чтобы закреплённый заголовок не вытеснял список.
- Положение списка сохраняется при закрытии и повторном открытии в том же уроке. При смене урока программа ориентируется на новый текущий элемент.
- Небольшая верхняя ручка декоративная; свайп для закрытия не обязателен.

Компромисс: из урока переход к основным разделам требует дополнительного шага «К курсу». Возможная альтернатива — компактная кнопка «Меню» в верхней панели урока. Она пока не принята и в макеты не добавлена.

## 3. Карта действий и переходов

| Экран / элемент | Действие | Результат | Важные состояния |
|---|---|---|---|
| Главная / «Продолжить обучение» | Открыть текущий урок | «Условные операторы» | Загрузка, ошибка; использовать актуальный доступ |
| Карточка / название курса | Открыть курс | Описание, прогресс, программа | Не начат, в процессе, завершён |
| SQL / «Начать» | Открыть первый доступный урок | Начало обучения | Не увеличивать число завершённых уроков |
| Программа / завершённый урок | Открыть повторно | Материал урока | Прогресс сохраняется |
| Программа / недоступный урок | Показать причину | Пояснение блокировки | Без перехода к закрытому материалу |
| Главная / «Все курсы» | Открыть список | «Мои курсы» | Фильтры, пустой список, загрузка, ошибка |
| Главная или список / «Открыть задание» | Открыть урок у задания | Форма или результат проверки | Прокрутить к заданию и перенести фокус на его заголовок |
| Задание / «Отправить на проверку» | Проверить поля и отправить | «На проверке» после подтверждения | Валидация, отправка, ошибка с сохранением данных |
| Задание / «Отправить повторно» | Отправить исправленное решение | Новая отправка на проверку | Доступно после «Нужны исправления»; комментарий преподавателя сохраняется |
| Задание / «Открыть решение» | Открыть сохранённый URL | Git-репозиторий или ветка | Новая вкладка с явным доступным обозначением; возможен внешний запрос авторизации |
| Занятие / «Подробнее» | Открыть компактное окно | Детали занятия и доступность подключения | Ожидание, доступно, завершено |
| Занятие / «Подключиться» | Открыть предоставленную ссылку | Внешнее онлайн-занятие | Только при разрешённом подключении и наличии ссылки; ошибку показать явно |
| Навигация / «Задания» | Открыть список заданий | Задания назначенных курсов | Название, курс, статус, «Открыть задание»; пусто, загрузка, ошибка |
| Навигация / «Онлайн-занятия» | Открыть список занятий | Ближайшие и завершённые занятия | Название, дата, МСК, время, состояние, «Подробнее» |
| Имя / аватар / меню профиля | Открыть небольшое меню | Имя «Александр» и «Выйти» | Имя — информация; отдельный экран профиля и настройки не добавляются |
| Меню / «Выйти» | Завершить сессию | Страница входа после подтверждения | Ожидание, ошибка без ложного выхода; интеграция требует согласования |
| Ошибка загрузки / «Повторить» | Повторить запрос | Данные или новая ошибка | Индикатор; сохранить выбранный фильтр |
| Урок / «Завершить урок» | Запросить завершение | «Урок завершён» после подтверждения | Ожидание, ошибка с повтором; следующий урок закрыт до успеха |
| Завершённый урок / «Следующий урок» | Открыть следующий доступный | «Циклы» для текущего примера | На последнем уроке — возврат к программе курса |
| Завершённый курс / «Повторить материал» | Открыть программу | Выбор завершённого урока | Прогресс не сбрасывается |
| Программа / заголовок модуля | Раскрыть или свернуть | Список уроков этого модуля | Состояние раскрытия и клавиатурный фокус |
| Урок / «Скачать» | Скачать вложение | Файл конспекта | Ошибка скачивания с повтором |
| Урок / Play | Запустить видео | Воспроизведение | Ожидание и ошибка; само воспроизведение не завершает урок |

Окно «Подробнее»: «Разбор практических задач по Java»; 18 ноября 2026 года; 19:00–20:30 МСК, UTC+3; длительность 90 минут; текстовый статус подключения. До начала — «Ожидает начала», без активной кнопки подключения. При доступности — «Подключиться». После окончания — «Занятие завершено», без обещания записи. Крестик, фон и Escape закрывают окно; правила фокуса аналогичны панели курса. Дата демонстрационная.

Минимальные разделы — простые списки, без дополнительных метрик, рейтингов и сложных фильтров. Для заданий достаточно фильтра по статусу; для занятий — переключения «Предстоящие» / «Завершённые».

Ещё не спроектированы полноразмерные экраны: список заданий, список онлайн-занятий, вход после выхода, другие уроки и страницы курсов Git/SQL. Не показаны визуально компактное окно занятия, меню профиля, ошибки видео и скачивания. Их назначение задано выше; отдельного экрана профиля пока нет.

## 5. Типографика

Основной веб-шрифт: Golos Text, кириллица и латиница, веса 400/500/600/700. Источник: [Google Fonts](https://fonts.google.com/specimen/Golos+Text), [репозиторий шрифта](https://github.com/googlefonts/golos-text). Код: [JetBrains Mono](https://www.jetbrains.com/lp/mono/), веса 400/500, с кириллицей. Предпочтительно самостоятельно размещённые WOFF2 с сохранением лицензий и font-display: swap.

Fallback интерфейса: "Golos Text", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Arial, sans-serif.

Fallback кода: "JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", monospace. Для учебного кода отключить лигатуры, чтобы состав операторов оставался очевидным.

## 6. Компоновка и адаптация

Шкала отступов: 4, 8, 12, 16, 24, 32, 40, 48, 64 px. Горизонтальные и вертикальные отступы компонентов используют эту шкалу.

| Ширина viewport | Компоновка |
|---|---|
| До 767 px | Одна колонка; поля страницы 16 px; нижняя навигация в основных разделах; урок без неё; программа в панели |
| 768–1023 px | Планшет: поля 24 px; боковое меню скрыто, основные разделы через нижнюю навигацию; главная в одну колонку; каталог максимум 2 колонки; программа урока в панели |
| От 1024 px | Боковое меню 232 px; поля страницы 32 px; межколоночный промежуток 24 px |
| От 1280 px | Поля страницы 40 px; основная рабочая область до 1200 px, центрируется внутри доступного места |

Главная desktop: текущий курс и занятие в отношении примерно 2:1, минимум 320 px для колонки занятия. При нехватке ширины занятие переносится ниже.

Урок desktop: глобальное меню 232 px, программа 240–260 px, статья занимает остаток, ширина текста до 760 px. В диапазоне 1024–1199 px программу переносить в панель, чтобы не сжимать материал. Видео занимает ширину статьи с пропорцией 16:9.

Карточки: радиус 12 px, граница 1 px, внутренний отступ 24 px desktop / 16 px mobile. Поля и кнопки: радиус 8 px. Панель: верхние углы 16 px. Статусы: радиус 999 px. Тени карточкам не нужны; панели и меню могут иметь тень 0 16px 48px rgba(0,0,0,0.32), то есть #000000 с alpha 32%.

Панель программы на мобильном: ширина 100%, высота до 88dvh, максимальная доступная высота ограничена безопасной областью экрана; отдельные области заголовка и списка. На планшете ширина до 560 px. Внутренние отступы 16 px, промежутки 12–16 px. При увеличении текста приоритет доступности закрытия и прокрутки выше фиксации заголовка.

Нижняя навигация: минимальная высота 64 px плюс нижний safe-area inset; контент имеет соответствующий нижний отступ, чтобы последняя карточка не скрывалась под меню.

Длинные названия переносятся; ряды уроков имеют минимальную высоту 56 px и увеличиваются по содержимому. На mobile причина блокировки идёт под названием, а не отдельной правой колонкой. Длинные списки прокручиваются вертикально; в программе не нужно помещать все 24 урока в один viewport. Фильтры разрешено переносить на следующую строку.

## 7. Компоненты и состояния

Общее правило: default, hover, focus-visible и active применяются ко всем доступным интерактивным элементам. Hover только для устройств с наведением. Disabled означает невозможность действия; loading означает выполняющийся запрос и защиту от дублей. Нефункциональным поверхностям не назначать искусственные hover и focus.

| Компонент | Правила и состояния |
|---|---|
| Primary button | Фон accent, текст on-accent; высота минимум 48 px; padding 12×20 px; hover/active по токенам; loading сохраняет ширину и подпись процесса; disabled по токенам |
| Secondary button | Прозрачная поверхность, control-border, text-primary; hover surface-hover, active surface-active; общий фокус; disabled и loading аналогичны primary |
| Текстовая кнопка / ссылка | Accent, без рамки; hover подчёркнут; active accent-hover; mobile область минимум 44×44; ссылка для перехода, кнопка для локального действия |
| Поле | Высота минимум 48 px, фон field, рамка control-border, padding 12×16; hover более заметная рамка text-secondary; focus-visible общий; ошибка рамка error и текст helper; disabled по токенам |
| Textarea | Минимум 112 px, те же состояния; вертикальное увеличение; постоянная метка над полем; комментарий явно необязателен |
| Карточка | Surface, border, радиус 12; только реальные ссылки и кнопки фокусируются; если вся карточка — одна ссылка, не вкладывать в неё другие интерактивные элементы |
| Статус | Текст + значок + мягкий фон; минимум 14/20; «На проверке» — нейтральный, «Принято» — success, «Нужны исправления» — warning; сам статус не кнопка |
| Прогресс | Трек disabled-bg, заполнение accent, высота 8 px, радиус 999; количество и процент текстом; без произвольных графиков |
| Навигация | Активный пункт: accent-soft, accent и дополнительный маркер; aria-current для текущего раздела; hover/active по поверхности; клавиатурный фокус |
| Модуль курса | Заголовок — кнопка раскрытия; chevron и aria-expanded; hover, active, focus-visible; раскрытие не завершает урок и не снимает блокировку |
| Ряд урока | Доступный — ссылка; текущий помечен текстом; завершённый открывается повторно; закрытый — ряд с пояснением, при необходимости отдельная кнопка информации вместо ссылки на материал |
| Ошибка | Error-soft, error-значок, ясная причина и применимое действие повтора; не очищать форму; ошибка поля связана с полем; сетевую ошибку показывать рядом с действием |
| Skeleton | Сохраняет приблизительные размеры будущего контента; skeleton и skeleton-highlight; необязательное плавное изменение opacity без градиента; при reduced-motion неподвижен |
| Выдвижная панель | Backdrop, surface, верхние углы 16; открыто/закрыто; внутренняя прокрутка; фокус и закрытие по разделу 2; loading/error списка внутри панели |
| Видео | Полоса воспроизведения занимает свободное место между Play и звуком/fullscreen; числа времени только из настоящих метаданных видео |
| Меню профиля | Небольшое раскрывающееся меню, имя и «Выйти»; фокус на доступных действиях; Escape/фон закрывают; возврат фокуса к имени/аватару |

Отправка решения: метка «Ссылка на решение» обязательна; комментарий необязателен. Валидация проверяет заполнение, структуру URL и HTTPS. Доступность приватного репозитория нельзя считать доказанной только по валидному URL. Во время отправки поля временно блокируются; при ошибке сохраняются и снова редактируются. После успешной отправки отображается сохранённое решение и статус «На проверке». После «Нужны исправления» поля доступны для повторной отправки.

### Прогресс и обновления

Ширина заполнения = completed / total × 100%; отображаемый целый процент = округление этого значения до ближайшего целого. Не рассчитывать ширину по округлённой подписи.

| Данные | Ширина полосы | Подпись |
|---|---|---|
| Java: 8 / 24 | 33,333…% | 33% |
| Git: 3 / 12 | 25% | 25% |
| SQL: не начат | Полосу можно не показывать | «Не начат» |
| Java после принятия текущего задания: 9 / 24 | 37,5% | 38% |
| Завершённый Java: 24 / 24 | 100% | 100% |

Если total неизвестно или равно нулю, числовой progress не строится. После подтверждения завершения обновляются все представления курса из единого источника данных. При неопределённом исходе запроса следующий урок остаётся закрытым до проверки актуального состояния; повтор должен безопасно согласовываться с backend.

## 8. Доступность

- Все действия доступны с клавиатуры; focus-visible не скрывается. Модальная панель удерживает фокус, фон исключается из взаимодействия.
- На мобильных устройствах интерактивная область не меньше 44×44 CSS px. Значок может быть 20 px внутри этой области.
- Статусы не передаются одним цветом: использовать текст и значок. Заблокированные уроки имеют видимую причину.
- У полей постоянные метки; placeholder их не заменяет. Ошибки связываются с полями, используются aria-invalid и aria-describedby.
- Области загрузки обозначаются aria-busy; подтверждение отправки и завершения объявляется ненавязчиво, важная ошибка — явно. Не объявлять каждое изменение видео или процента как срочное.
- При увеличении текста до 200% и масштабировании страницы компоненты растут, названия переносятся, колонки переходят в одну; кнопки и пояснения не обрезаются фиксированной высотой.
- Нет горизонтального скролла всей страницы. У гибких колонок min-width: 0; длинные URL переносятся там, где это не поле редактирования.
- Длинный код сохраняет форматирование и может прокручиваться внутри собственного блока; контейнер доступен клавиатуре и имеет понятное название. Не уменьшать весь текст ради длинной строки.
- Вложения, внешние ссылки и закрытие панели имеют доступные имена. Декоративные значки скрываются от скринридера.
- Progress имеет доступное имя и числовые значения; видимый счётчик уроков остаётся рядом.
- Анимация панели 160–200 мс; при prefers-reduced-motion отключается. Не перемещать фокус автоматически при каждом обновлении статуса.
- Проверенные цветовые пары перечислены в разделе 4. Проверки клавиатуры, масштабирования, скринридера и окончательной вёрстки ещё требуются; соответствие всего продукта стандарту не заявляется.

## 9. Иконки

Одна библиотека: [Lucide React](https://lucide.dev/guide/react/). Размеры 20 px для рядов и кнопок, 24 px для основной навигации; stroke-width 2, единые округлённые концы и соединения линий. В мобильной нижней навигации — 24 px. Не смешивать контурные наборы и произвольные технологические логотипы. Семантические значки: check, clock, lock, alert, chevron, arrow, book, calendar, file, close. У кнопок только со значком обязательно доступное имя.
