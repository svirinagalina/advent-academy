# Референсы дизайна

Положи сюда HTML-макет будущего сайта, например `index.html`, и связанные с ним
CSS, JavaScript, изображения и шрифты. Можно добавить несколько страниц и
скриншоты. Сохраняй относительные пути между файлами.

Это исходный материал для переноса дизайна в React-компоненты. Каталог не
публикуется Next.js, не включается в Docker-образ и исключён из lint/typecheck.
Рабочие ресурсы сайта после переноса будут находиться в `public/`.
