# Advent Academy — frontend

Отдельное приложение Next.js (App Router), React, TypeScript и Tailwind CSS.
Содержит адаптивный кабинет ученика по макетам из `design-reference/`:
главную, список курсов, программу курса, урок, задания и онлайн-занятия.
На этом этапе используются демонстрационные данные без подключения Java API
и реальной авторизации. В Gradle приложение не включается.

## Локальный запуск

Нужен Node.js 24 LTS. Версия зафиксирована в `.nvmrc`; при использовании nvm
выполни `nvm install` и `nvm use` из этой директории.

```bash
cd frontend
npm ci
cp -n .env.example .env.local
npm run dev
```

Открой http://localhost:3000. Если порт занят: `npm run dev -- --port 3001`.

## Проверки и сборка

```bash
npm run check
npm run build
npm run start
```

`check` запускает Biome и TypeScript. `build` создаёт production-сборку.
Для проверки пользовательского сценария открой Java → «Продолжить обучение»,
отправь HTTPS-ссылку на решение, затем в меню «Демо» выбери ответ преподавателя.
Принятие завершает урок и открывает «Циклы». У уроков без обязательного задания
есть кнопка «Завершить урок».

Меню «Демо» также показывает пустой список, загрузку, ошибку списка и сбой
отправки/завершения. Эти переключатели проверяют UI без сетевых запросов.
Прогресс, черновик и статус задания сохраняются в localStorage этого браузера;
«Сбросить прогресс» восстанавливает исходные данные. В приватном режиме или
при запрете хранилища данные могут не пережить перезагрузку.

Все экраны доступны по ссылкам приложения; состояние страницы хранится в
query-параметрах (`?view=courses`, `?view=course&course=java`,
`?view=lesson&course=java&lesson=conditions`, `?view=assignments`,
`?view=meetings`). Работают прямые ссылки и история браузера.

Видеоблок — явно обозначенный заполнитель; вложение — демонстрационный
текстовый файл. Реального видеоматериала, подключения к занятию и проверки
заданий сервером пока нет. Дата занятия также демонстрационная.

Шрифты Golos Text и JetBrains Mono загружаются через next/font во время
сборки и затем отдаются приложением локально; сборке нужен доступ к Google Fonts.
Иконки выполнены встроенными контурными SVG без дополнительных зависимостей.

## Структура

- `src/app/` — страницы, layout и общие стили.
- `src/components/` — интерфейс кабинета и общие компоненты.
- `src/lib/demo.ts` — демонстрационные курсы, доступность уроков и нормализация сохранённого состояния.
- `public/` — публичные изображения, шрифты и другие ресурсы сайта.
- `design-reference/` — сюда положи HTML-дизайн и его исходные ресурсы.

## Docker

Из корня репозитория, без запуска остальных сервисов:

```bash
docker compose --profile frontend up -d --build frontend
```

Сайт доступен на http://localhost:3000. Для остановки только фронтенда:
`docker compose stop frontend`.

Самостоятельная сборка: `docker build -f frontend/Dockerfile -t advent-frontend .`.
Контекст — корень репозитория, как в существующем Docker CI.
Контейнер запускает standalone-сборку от непривилегированного пользователя.

## Интеграция

Будущие запросы к Java-сервисам будут идти через `api-gateway`. Для авторизации
планируется серверная прослойка; текущий шаблон ещё не реализует сессии, BFF
или хранение токенов. HTML из `design-reference/` не исполняется приложением.
